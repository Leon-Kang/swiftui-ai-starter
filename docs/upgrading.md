# Upgrading generated projects

生成项目保留 `starter-version.json`，用于识别最初采用的规范版本。starter 更新不会自动覆盖
产品项目。

每次升级必须：

1. 阅读 release diff 和迁移说明。
2. 在独立分支中应用配置和共享层变化。
3. 保留产品自己的依赖注入、provider、签名和本地化配置。
4. 运行约定检查、完整模板测试、产品构建和产品测试。
5. 对持久化格式、缓存和并发边界变化提供回滚方案。
6. 只通过受保护分支和必需 CI 合并。

不要用 starter 更新脚本覆盖已经生成并持续开发的产品目录。
